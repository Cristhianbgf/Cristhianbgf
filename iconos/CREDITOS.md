# Créditos de los logos

Los logos son marcas de sus dueños y se usan solo para nombrar las herramientas.

- Glifos de [Simple Icons](https://simpleicons.org) (CC0 1.0), salvo:
  - Git, de Jason Long (CC BY 3.0);
  - R, de The R Foundation (CC BY-SA 4.0).
- Logos a color de [Devicon](https://devicon.dev) (MIT): Python, R, pandas, NumPy, Jupyter, scikit-learn, PyTorch, TensorFlow, Anaconda, Docker, pytest, Git, GitHub y Markdown.
- Íconos de los títulos de [Octicons](https://primer.style/octicons) (MIT).
- Logo de [xarray](https://github.com/pydata/xarray) (Apache 2.0).
